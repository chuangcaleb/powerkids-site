# v3 Design Audit

**Purpose:** record what the v3 site actually looked like, in values, so `DESIGN.md` can be authored deliberately instead of reverse-engineered twice.
**Read this when:** writing `DESIGN.md` or building the token layer in Phase 2.

This is an audit, not a specification. It describes what exists; `DESIGN.md` will decide what to keep.

---

## Character

Playful, high-contrast, hand-drawn. A marker-pen display face, thick black borders with hard offset shadows, primary red and blue used as loud accents, and a heart motif recurring as a section divider. It reads as a children's-craft aesthetic rather than a corporate one — that is the brand's actual equity and the rebuild should preserve it.

---

## Colour

Declared as HSL channel triples for shadcn compatibility. Converted values below.

### Brand accents — the only chromatic colours

| Token           | HSL            | Hex       |
| --------------- | -------------- | --------- |
| `--accent-red`  | `0 100% 45%`   | `#e60000` |
| `--accent-blue` | `240 100% 46%` | `#0000eb` |

Both accents are fully saturated. Red carries "Power", warmth, and urgency (register CTAs); blue carries "Kids", calm, and secondary actions. The wordmark always splits `Power` red / `Kids` blue. The Safari pinned-tab colour is `#e20000`, a near-miss of `--accent-red` — **unify in v4**.

### Neutrals — pure greyscale, zero hue

| Token                | HSL             | Notes                               |
| -------------------- | --------------- | ----------------------------------- |
| `--background`       | `0 0% 100%`     | Pure white                          |
| `--foreground`       | `0 0% 3.9%`     | Near-black text                     |
| `--primary`          | `0 0% 9%`       |                                     |
| `--muted`            | `0 0% 96.1%`    |                                     |
| `--muted-foreground` | `0 0% 45.1%`    |                                     |
| `--border`           | `0 0% 0%`       | Pure black — the thick outline look |
| `--ring`             | `0 0% 63.9%`    |                                     |
| `--destructive`      | `0 84.2% 60.2%` | shadcn default, effectively unused  |

Most of the palette is untouched shadcn boilerplate. Only `--border: black`, the two accents, and pure-white background are genuine design decisions. **Everything else is default noise and should not be carried over.**

No dark mode existed.

### Contrast findings

- `#0000eb` on white ≈ 8.6:1 — passes AA and AAA for body text.
- `#e60000` on white ≈ 4.0:1 — **fails AA for body text** (needs 4.5:1); passes only for large text (≥24px or ≥19px bold).
- White text on `#e60000` (used inside `<mark>`) ≈ 5.3:1 — passes AA for normal text.

The red is only safe as a large-text or filled-background colour. `DESIGN.md` must state this, or the rebuild will repeat it. Darkening red to roughly `#cc0000` reaches 5.3:1 on white and keeps the character.

## Typography

| Role    | Stack                                        |
| ------- | -------------------------------------------- |
| Display | `"Marker Felt", "Comic Sans MS", sans-serif` |
| Body    | `"PT Sans", sans-serif`                      |

Marker Felt is applied via a `font-marker` class on every heading, the wordmark, pills, and card titles. Self-hosted as `marker-felt.ttf` and preloaded.

⚠️ **Licensing risk.** Marker Felt is an Apple system font, bundled with macOS/iOS, and redistributing the `.ttf` from a web server is very likely outside its licence. The fallback (`Comic Sans MS`) is a Microsoft font with the same problem, and neither is available to Linux or Android visitors — a large share of Malaysian mobile traffic has been seeing the generic sans fallback all along. **Resolve in Phase 2**: source a licensed marker/handwriting webfont with a real open licence. Candidates worth evaluating: _Patrick Hand_, _Gochi Hand_, _Caveat_, _Architects Daughter_ (all SIL OFL, on Google Fonts).

PT Sans is referenced but never loaded — no `@font-face`, no font CDN link. v3 has been silently rendering body copy in each device's default sans. **Load it properly in v4, or pick a different body face on purpose.**

### Fluid scale

Generated by `tailwind-utopia`:

| Parameter         | Value              |
| ----------------- | ------------------ |
| Min viewport size | 16px               |
| Min scale ratio   | 1.25 (major third) |
| Max viewport      | 1280px             |
| Max size          | 19px               |
| Max scale ratio   | 1.37               |
| `useClamp`        | `false`            |

Steps used in practice run from `step--2` to `step-5`. Space utilities (`fl-p-*`, `fl-gap-*`, `fl-space-y-*`) come from the same generator, tiers `3xs` through `4xl`.

The Utopia approach carries over directly — the reference project uses `utopia-core-scss` with the same idea. Keep the ratios as a starting point.

## Shape and depth

```css
--radius: 0.5rem; /* lg; md = radius - 2px; sm = radius - 4px */
```

The signature treatment:

```css
.pk-border {
  border-width: 0.2em;
  box-shadow: 6px 6px 0px hsl(var(--border)); /* hard black offset, no blur */
}
```

Hard offset shadow, never a soft blur. This is the opposite of the reference project's "whisper shadow" rule and must not be copied from it — the two design systems disagree deliberately.

Cards use a black border plus the offset shadow. Some cards use a "tab" header style (`cardTabHeaderStyle`) where a heading sits above the card with the top-left radius squared off, like a file tab.

## Motifs

**Heart rule.** `<hr>` is 0.15em thick with `heart.svg` centred on it via `::after`, pulled up over the line with a background-coloured gutter. Used between homepage sections and between school entries. This is the site's most distinctive element and should survive the rebuild — likely as a `divider` variant rather than a bare `hr`.

**Highlight sweep.** `<mark>` animates a left-to-right colour wipe over 1.5s on load, using a 200%-wide linear gradient with the fill colour on the left half. Colour comes from `--highlight`, set by a `.red` or `.blue` class. Text turns white.
⚠️ No `prefers-reduced-motion` guard in v3. Add one in v4.

**Blob.** `blob.svg` sits behind the Register section as a full-bleed organic shape, with white text over it.

**Rotated logo.** The logo appears rotated 12° as decoration on the About page.

**Opacity-ladder heading.** The disabled Our Team section repeated the word "Team" four times at 40%/20%/10%/5% opacity for a fading-echo effect. Worth reviving if that section returns.

## Layout

v3 had no primitive system. Layout was per-component Tailwind grid and flex classes with heavy breakpoint-specific overrides — `xl:row-start-1 xl:col-start-1 mr-auto`, `sm:max-md:fl-ml-m`, and similar, including hard-coded per-index card positioning arrays on the homepage program and event grids.

The one shared abstraction was `Section.astro`:

| Prop           | Values                                 | Effect                                                                         |
| -------------- | -------------------------------------- | ------------------------------------------------------------------------------ |
| `contentWidth` | `md` \| `lg` \| `xl` \| `unset`        | `max-w-screen-lg` / `max-w-screen-xl` / `max-w-[1500px]` / none. Default `lg`. |
| `paddingY`     | `top` \| `bottom` \| `both` \| `unset` | `fl-py-2xl` and variants. Default `both`.                                      |

Horizontal padding was always `fl-px-s md:fl-px-xs`.

Custom breakpoint: `sm` overridden to `475px`.

`Section` maps onto the `wrapper` primitive almost exactly, and most of the ad-hoc grids map onto `grid-auto`, `switcher`, or `repel`. This is the single largest simplification available in the rebuild — and the reason the block set is defined in terms of primitives.

`html` sets `scroll-behavior: smooth` and `scroll-padding-top: var(--fs-xl)` for the anchor links.

## Components

Built on shadcn/ui + Radix: `accordion`, `button`, `card`, `navigation-menu`, `sheet` (mobile nav drawer). Two brand components used `class-variance-authority`:

- **Pill** — eyebrow label. Colours `default` / `muted` / `red` / `blue` (accent variants use a 10% tint background with full-strength text); sizes `xs` / `md` / `lg`.
- **SuperHead** — coloured lead-in above a heading. Same colour set, sizes map to type steps.

Both are thin enough to reimplement directly as CSS Module variants — no CVA, no Radix needed.

Radix is genuinely needed only for the mobile nav drawer and the accordion. Everything else was a styled `<div>`.

---

## Carry-over recommendations

**Keep:**

- Red/blue dual accent and the `Power`/`Kids` wordmark split
- Marker display face (with a properly licensed font)
- Hard offset shadow + thick black border
- Heart rule divider
- Highlight sweep on `<mark>`, gated on `prefers-reduced-motion`
- Utopia fluid type and space
- Pure white background

**Fix:**

- Red's contrast ratio for body-sized text
- Font licensing and the never-loaded body font
- The `#e20000` / `#e60000` mismatch
- Missing reduced-motion guards

**Drop:**

- The unused shadcn palette
- Per-index positioning arrays and breakpoint-specific overrides — replace with primitives
- CVA and most Radix components
