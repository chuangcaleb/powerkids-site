# Archived phases

Records of completed phases. **Outdated — do not treat any of these as current spec.**

They describe what was planned and what was true at the time, and they were not updated as later phases changed things. Field lists, block counts, and API names in here are frozen at the moment the phase closed; several are already wrong.

**Read one only to recover why a past decision was made.** For anything about current state, read the code, `docs/architecture/`, or the live phase file.

Traps sections are the exception worth mining — each landmine listed already cost real time.
